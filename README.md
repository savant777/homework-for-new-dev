# 🚀 Technical Assessment: Homework for New Dev

This repository contains a comprehensive **Technical Assessment** consisting of three distinct exercises, ranging from desktop applications to API integration and responsive web design. Each project demonstrates different facets of software development and problem-solving.

---

## 📂 Project Structure

```bash
homework-for-new-dev/
├── class_registration_app/     # Ex 1: Desktop Application (C# .NET)
├── line_oa_api/                # Ex 2: Backend & Messaging API (Node.js)
└── responsive_html/            # Ex 3: Frontend Development (HTML/CSS)
```
---

## 📝 Project Details
<ol>
  <li><b>Class Registration App (WinForms + SQL)</b><br><i>A desktop solution for managing academic class enrollments.</i>
    <ul>
      <li><b>Tech Stack:</b> C# WinForms, .NET Framework, SQL Server LocalDB (.mdf).</li>
      <li><b>Core Features:</b> CRUD operations for class management, dynamic image loading (Posters), and local database persistence.</li>
      <li><b>💡 Problem-Solving Highlight:</b> Originally tasked with PowerApps + SharePoint. However, due to environment constraints, I proactively architected a C# WinForms alternative. This ensured a functional deliverable that effectively demonstrates database schema design and data management logic.</li>
      <li><b>Skills:</b> Software Architecture, Database Design, C# Programming.</li>
    </ul>
  </li>
  <br>
  <li><b>Line OA API (Backend Messaging)</b><br><i>An API-driven solution for Line Official Account integration.</i>
    <ul>
      <li><b>Tech Stack:</b> Node.js, Express.js, Line Messaging API.</li>
      <li><b>Core Features:</b> Environment variable management, webhook handling, and custom message previews (Text/Flex messages).</li>
      <li><b>Security:</b> Implemented .env configuration for secure credential management.</li>
      <li><b>Skills:</b> Backend Development, API Integration, Webhooks.</li>
    </ul>
  </li>
  <br>
  <li><b>Responsive HTML (Pixel-Perfect Frontend)</b><br><i>A fully responsive static website built from a design brief.</i>
    <ul>
      <li><b>Tech Stack:</b> HTML5, CSS3 (No JavaScript for optimized performance).</li>
      <li><b>Deliverables:</b> Pixel-perfect implementation from a design brief, ensuring cross-device compatibility (Desktop & Mobile).</li>
      <li>🚀 <a href="https://savant777.github.io/homework-for-new-dev/responsive_html/" target="_blank">Live Demo</a></li>
      <li><b>Skills:</b> Frontend Development, Responsive Web Design (RWD).</li>
    </ul>
  </li>
</ol>
